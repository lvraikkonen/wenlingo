## Scope

Validate the V0.5b AI infrastructure and sentence challenge vertical slice after
the latest `main` branch is pushed to GitHub and Railway Dev finishes deploying.

This checklist covers:

- Resend / Dev Echo Magic Code readiness.
- AI-generated or fallback sentence challenge creation.
- Sentence challenge completion, short feedback, XP settlement, and reaction.
- `自己带句子来练` legacy free-input compatibility.
- Parent summary sentence progress.
- Admin Alpha AI usage aggregate, revoked invite toggle, and privacy boundary.
- Daily limit handling and cross-family access rejection.

Do not record raw invite codes, Admin token, Magic Codes other than the documented
Dev Echo code, full emails, full phone numbers, child writing text, raw prompts,
raw LLM responses, or AI feedback bodies in this file.
