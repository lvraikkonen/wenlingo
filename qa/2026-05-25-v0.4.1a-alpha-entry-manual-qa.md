# V0.4.1a Alpha Entry Manual QA

Date: 2026-05-25

## Scope

Validate the minimum Alpha entry flow for 3-5 trusted families:

```text
/alpha/start
-> Alpha notice
-> Alpha parent context
-> child creation
-> device handoff
-> child dashboard
-> V0.4 assessment
-> parent summary
```

## Checklist

- [ ] Fresh Alpha user opens `/alpha/start`.
- [ ] Alpha notice appears before child data collection.
- [ ] Notice says not to enter real name, school, address, phone, birthdate, or photo.
- [ ] Notice discloses that child writing may be sent to AI services.
- [ ] Parent accepts Alpha notice and creates Alpha parent context.
- [ ] Reopening `/alpha/start` in the same browser offers `继续使用当前 Alpha 家庭`.
- [ ] Parent creates child with valid nickname and grade.
- [ ] Parent cannot create child with empty nickname.
- [ ] Parent cannot create child with nickname longer than 24 characters.
- [ ] Parent cannot create child with invalid grade outside 3-6.
- [ ] Parent can create a second child.
- [ ] Both children appear in parent children list.
- [ ] Parent sees device handoff confirmation.
- [ ] Handoff button enters existing child dashboard route `/children/{studentId}`.
- [ ] New child dashboard recommends `入门小试炼`.
- [ ] Child completes V0.4 assessment.
- [ ] Ability sketch appears.
- [ ] Child returns to dashboard.
- [ ] Dashboard no longer recommends assessment as the main task.
- [ ] Parent opens `/parent/children/{studentId}/summary`.
- [ ] New child summary with no training shows friendly empty state.
- [ ] Summary after assessment shows real assessment count.
- [ ] Summary after assessment shows real `AbilityHistory` deltas.
- [ ] Parent summary for a child from another parent is rejected by backend.
- [ ] Demo family entry at `/` still works.
- [ ] Existing `FamilyTopbar` demo navigation still works.
- [ ] Existing V0.4 assessment tests still pass.
- [ ] Reading Canyon, if visible, is clearly marked as under construction.
- [ ] Browser storage contains only `wenlingo_alpha_parent_id` for Alpha parent context.
- [ ] URLs do not contain child real names or sensitive data.
