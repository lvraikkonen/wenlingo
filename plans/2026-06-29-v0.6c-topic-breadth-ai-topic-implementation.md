# V0.6c Topic Breadth + AI Topic Thin Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship V0.6c Writing Castle topic-family breadth plus the smallest safe AI-topic idea flow: interest + grade -> exactly 3 child-safe ideas -> child selects one -> existing prewriting flow.

**Architecture:** Keep V0.6b's `TopicType -> ScaffoldTemplate -> SourceChain -> QA Matrix` shape. Backend remains the template and provenance source of truth; frontend renders API-provided families and reuses the existing prewriting wizard after AI-topic selection. AI topic selection uses a short-lived server-side `WritingTopicIdeaBatch` record so selected ideas are server-verified and double-click selection is idempotent.

**Tech Stack:** FastAPI, SQLModel, Alembic, Pydantic v2, existing Prompt Registry/ModelRouter/AI runner, Next.js App Router, React Testing Library/Vitest, Playwright.

## Hard Guards

1. `SCHEMA_VERSION` remains exactly `v0.6b.1`. New templates get `.v0.6c` only through `scaffold_template_version`.
2. `practical_writing` source policy is slot-level in code, not prompt-only:
   - `topic_requirement` may support structural slots: `format_type`, `audience_or_date`, `date_weather`, `recipient`, `signature_date`, `signature_or_date`.
   - `topic_requirement` alone cannot support content slots: `main_message`, `reason_or_background`, `specific_details`, `closing_or_call`, `day_event`, `key_detail`, `feeling_or_discovery`, `problem_observed`, `specific_suggestions`.
   - LLM output for those content slots needs `real_experience` or `observation`; child-edited persistence may add `child_confirmed`.
3. `story_adaptation` source policy is slot-level in code, not prompt-only:
   - `topic_requirement` and `reading_material` may support `original_basis` and `kept_elements`.
   - `new_event`, `new_ending`, and `new_meaning` require `imagined_setting` in LLM output or `child_confirmed` through child-edited persistence.
4. AI topic ideas have server-side provenance:
   - `ai-topic-ideas` creates `WritingTopicIdeaBatch`, not `Essay`.
   - `ai-topic-essay` accepts `idea_batch_id + selected_idea_id`, not client-provided title/type as authority.
   - Same `idea_batch_id + selected_idea_id + student_id` returns exactly one Essay even if the button is double-clicked.
5. Practical-writing true variants are real:
   - `diary`, `letter`, and `proposal` each have distinct slots and outline sections.
   - They are not aliases in V0.6c.
6. Parent summary tests are release gate:
   - Backend includes `tests/test_alpha_api.py`.
   - Web includes `apps/web/tests/alpha_summary.test.tsx`.
   - AI-topic essays show `题目来源：AI 出题灵感，孩子选择` and `AI 正文：没有生成可直接照抄的作文正文`.
7. AI topic generation has no hidden fallback topics:
   - `writing_topic_idea_generation` passes `deterministic_fallback_factory=None`.
   - Failed or invalid generation logs an LLM failure and returns retry/later UI copy.
8. V0.6c does not implement essay archive, multi-round revision, delete/hide, parent weekly report redesign, streaming, or admin template editor.

PRACTICAL_STRUCTURAL_SLOTS = {
    "format_type",
    "audience_or_date",
    "date_weather",
    "recipient",
    "signature_date",
    "signature_or_date",
    "proposal_topic",
}
PRACTICAL_CONTENT_SLOTS = {
    "main_message",
    "reason_or_background",
    "specific_details",
    "closing_or_call",
    "day_event",
    "key_detail",
    "feeling_or_discovery",
    "problem_observed",
    "specific_suggestions",
}
STORY_ADAPTATION_SOURCE_SLOTS = {"original_basis", "kept_elements"}
STORY_ADAPTATION_CHILD_DECISION_SLOTS = {"change_point", "new_event", "new_ending", "new_meaning"}


def source_types(source_refs: list[dict[str, Any]]) -> set[str]:
    return {ref["source_type"] for ref in normalize_source_refs(source_refs)}


def validate_slot_level_source_policy(
    *,
    topic_type: str,
    slot_id: str,
    source_refs: list[dict[str, Any]],
) -> None:
    types = source_types(source_refs)
    if topic_type == "practical_writing" and slot_id in PRACTICAL_CONTENT_SLOTS:
        if not types.intersection({"real_experience", "observation", "child_confirmed"}):
            raise ValueError(f"{slot_id} requires child-provided source")
    if topic_type == "story_adaptation" and slot_id in STORY_ADAPTATION_CHILD_DECISION_SLOTS:
        if not types.intersection({"imagined_setting", "child_confirmed"}):
            raise ValueError(f"{slot_id} requires imagined_setting or child confirmation")
```

class WritingTopicIdea(BaseModel):
    model_config = ConfigDict(extra="forbid")

    id: NonBlankStr = Field(max_length=40)
    title: NonBlankStr = Field(max_length=60)
    topic_type: SupportedTopicType
    topic_variant: str = Field(default="default", max_length=80)
    why_it_fits_child_interest: NonBlankStr = Field(max_length=80)
    practice_focus: NonBlankStr = Field(max_length=60)
    child_safe_prompt: NonBlankStr = Field(max_length=120)

    @model_validator(mode="after")
    def reject_finished_story_shapes(self) -> "WritingTopicIdea":
        joined = f"{self.title} {self.child_safe_prompt}"
        if "\n" in joined or "\r" in joined:
            raise ValueError("topic ideas cannot contain newlines")
        cjk_count = sum(1 for char in self.title if "\u4e00" <= char <= "\u9fff")
        if cjk_count > 30:
            raise ValueError("topic idea title has more than 30 CJK characters")
        forbidden = ("我明白了", "最后我", "那天我", "从此我")
        if any(pattern in joined for pattern in forbidden):
            raise ValueError("topic idea reads like finished story content")
        return self

    ideas: list[WritingTopicIdea] = Field(min_length=3, max_length=3)

    @model_validator(mode="after")
    def reject_duplicate_ids(self) -> "WritingTopicIdeasResult":
        ids = [idea.id for idea in self.ideas]

  const [isSelecting, setIsSelecting] = useState(false);
  const [error, setError] = useState("");

  async function generate() {
    setIsGenerating(true);
    setError("");
    try {
      const response = await generateAiTopicIdeas(studentId, { interest_text: interestText });
      setBatchId(response.idea_batch_id);
      setIdeas(response.ideas);
    } catch {
      setError("题目灵感暂时没有生成成功，可以重试，或者先用老师题目/直接写初稿。");
    } finally {
      setIsGenerating(false);
    }
  }

  async function selectIdea(idea: AiTopicIdea) {
    if (!batchId || isSelecting) {
      return;
    }
    setSelectedIdeaId(idea.id);
    setIsSelecting(true);
    setError("");
    try {
      const response = await createAiTopicEssay(studentId, {
        idea_batch_id: batchId,
        selected_idea_id: idea.id,
      });
      onEssayCreated(response.essay);
    } catch {
      setError("这个题目没有保存成功，请重新生成后再选一次。");
    } finally {
      setIsSelecting(false);
    }
  }

  return (
    <section className="rounded-lg border border-[var(--wen-border)] bg-white p-6 shadow-sm">
      <label className="block font-semibold">
        兴趣或想写的方向
        <input
          className="mt-2 w-full rounded-lg border border-[var(--wen-border)] px-3 py-2 font-normal"
          value={interestText}
          onChange={(event) => setInterestText(event.target.value)}
          maxLength={120}
        />
      </label>
      <button
        className="mt-4 inline-flex items-center gap-2 rounded-lg bg-[var(--wen-orange)] px-4 py-2 font-semibold text-white disabled:opacity-60"
        type="button"
        disabled={isGenerating || isSelecting}
        onClick={generate}
      >
        {isGenerating ? <Loader2 size={18} className="animate-spin" aria-hidden="true" /> : null}
        生成题目灵感
      </button>
      {ideas.length > 0 ? (
        <div className="mt-5 grid gap-3">
          {ideas.map((idea) => (
            <article key={idea.id} className="rounded-lg border border-[var(--wen-border)] bg-[var(--wen-bg)] p-4">
              <h2 className="font-bold">{idea.title}</h2>
              <p className="mt-2 text-sm text-[var(--wen-muted)]">{idea.practice_focus}</p>
              <button
                className="mt-3 rounded-lg bg-[var(--wen-leaf)] px-4 py-2 font-semibold text-white disabled:opacity-60"
                type="button"
                disabled={isSelecting}
                onClick={() => selectIdea(idea)}
              >
                {isSelecting && selectedIdeaId === idea.id ? "正在保存" : "选择这个题目"}
              </button>
            </article>
          ))}
        </div>
      ) : null}
      {error ? <p role="alert" className="mt-3 rounded-lg border border-[var(--wen-orange)] bg-white p-4 font-semibold">{error}</p> : null}
    </section>
  );
}
```
