# V0.5b.1 Alpha Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the V0.5b.1 Alpha expansion release gates from `specs/2026-06-13-v0.5b.1-alpha-polish-design.md`.

**Architecture:** Keep the V0.5b backend and auth architecture intact. Add explicit backend signals where the frontend currently infers state, add small reusable frontend components for assessment nudges and AI waiting states, demote legacy localStorage parent identity to migration-only, and make Admin cost display honest without starting V0.5c ModelRouter or pricing-registry work.

**Tech Stack:** FastAPI, SQLModel, Pydantic Settings, pytest, Next.js App Router, React, TypeScript, Vitest, Testing Library, Railway Dev manual QA.

---

## Scope Guardrails

- Do not add ModelRouter, provider fallback, per-task model config, or model-level cost registry.
- Do not add new sentence challenge types.
- Do not build Reading Canyon v1 or Writing Castle pre-writing.
- Do not replace the server-side parent session architecture.
- Do not hard-block children from sentence/essay practice before assessment.
- Do not hardcode new LLM prompts in service or route files. Any future LLM task must use Prompt Registry per `AGENTS.md`.

- [ ] **Step 5: Create assessment recommendation hook**

Create `apps/web/src/lib/useAssessmentRecommendation.ts`:

```ts
"use client";

import { useEffect, useState } from "react";
import { getDashboard, isUnauthorizedError } from "./api";

export function useAssessmentRecommendation(studentId: string) {
  const [isRecommended, setIsRecommended] = useState(false);
  const [isDismissed, setIsDismissed] = useState(false);

  useEffect(() => {
    let active = true;
    setIsDismissed(false);
    setIsRecommended(false);

    getDashboard(studentId)
      .then((dashboard) => {
        if (active) {
          setIsRecommended(dashboard.assessment_recommended);
        }
      })
      .catch((error: unknown) => {
        if (active && !isUnauthorizedError(error)) {
```

```ts
    if (existing) {

    return next;
  } catch {

  }
}
```
