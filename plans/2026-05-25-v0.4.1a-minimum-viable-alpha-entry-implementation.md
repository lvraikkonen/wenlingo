# V0.4.1a Minimum Viable Alpha Entry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the minimum Alpha family entry path: real server-side Alpha parent, browser-held parent context, child creation, device handoff, V0.4 assessment continuity, and minimal parent summary from real data.

**Architecture:** Add an additive FastAPI `alpha` route module using existing `ParentUser`, `StudentProfile`, and `AbilityProfile` tables, with no migration. Add focused Next.js Alpha parent pages that store only `wenlingo_alpha_parent_id` in `localStorage` and call parent-scoped APIs. Preserve the existing demo path, `FamilyTopbar`, and V0.4 assessment service.

**Tech Stack:** FastAPI, SQLModel, Pydantic, pytest, Next.js App Router, React client components, Vitest, Testing Library, localStorage, Railway services, Railway PostgreSQL for Alpha deployment.

```python
from collections import defaultdict
from uuid import uuid4

from fastapi import APIRouter, Depends, HTTPException
from pydantic import BaseModel, Field, field_validator
from sqlmodel import Session, select

from app.api.deps import get_db_session
from app.domain.enums import StudentPersona
from app.domain.models import (
    AbilityHistory,
    AbilityProfile,
    Assessment,
    Essay,
    ParentUser,
    SentenceTraining,
    StudentProfile,
)

router = APIRouter(prefix="/api/alpha", tags=["alpha"])

ABILITY_LABELS = {
    "expression": "表达力",
    "observation": "观察力",
    "structure": "结构力",
    "revision": "修改力",
    "comprehension": "阅读理解力",
    "summarization": "概括力",
}
ABILITY_ORDER = [
    "expression",
    "observation",
    "structure",
    "revision",
    "comprehension",
    "summarization",
]


class AlphaParentCreate(BaseModel):
    display_name: str = Field(default="Alpha 家长", max_length=40)

    @field_validator("display_name")
    @classmethod
    def normalize_display_name(cls, value: str) -> str:
        trimmed = value.strip()
        return trimmed or "Alpha 家长"


class AlphaChildCreate(BaseModel):
    nickname: str
    grade: int = Field(ge=3, le=6)

    @field_validator("nickname")
    @classmethod
    def normalize_nickname(cls, value: str) -> str:
        trimmed = value.strip()
        if not trimmed:
            raise ValueError("nickname is required")
        if len(trimmed) > 24:
            raise ValueError("nickname must be 24 characters or fewer")
        return trimmed


def _parent_payload(parent: ParentUser) -> dict[str, str]:
    return {"id": parent.id, "display_name": parent.display_name}


def _student_payload(student: StudentProfile) -> dict[str, object]:
    return {
        "id": student.id,
        "name": student.name,
        "grade_label": student.grade_label,
        "persona": student.persona,
        "level": student.level,
        "xp": student.xp,
    }


def _dashboard_url(student_id: str) -> str:
    return f"/children/{student_id}"


def _summary_url(student_id: str) -> str:
    return f"/parent/children/{student_id}/summary"


def _get_alpha_parent(session: Session, parent_id: str) -> ParentUser:
    parent = session.get(ParentUser, parent_id)
    if not parent:
        raise HTTPException(status_code=404, detail="alpha parent not found")
    return parent


def _get_parent_child(session: Session, parent_id: str, student_id: str) -> StudentProfile:
    student = session.get(StudentProfile, student_id)
    if not student or student.parent_id != parent_id:
        raise HTTPException(status_code=404, detail="student not found")
    return student


@router.post("/parents", status_code=201)
def create_alpha_parent(
    request: AlphaParentCreate,
    session: Session = Depends(get_db_session),
):
    parent = ParentUser(
        email=f"alpha-{uuid4()}@wenlingo.local",
        display_name=request.display_name,
    )
    session.add(parent)
    session.commit()
    session.refresh(parent)
    return {"parent": _parent_payload(parent), "children_url": "/parent/children"}


@router.get("/parents/{parent_id}/children")
def list_alpha_children(parent_id: str, session: Session = Depends(get_db_session)):
    parent = _get_alpha_parent(session, parent_id)
    students = session.exec(
        select(StudentProfile)
        .where(StudentProfile.parent_id == parent.id)
        .order_by(StudentProfile.created_at, StudentProfile.id)
    ).all()
    student_ids = [student.id for student in students]
    assessments = (
        session.exec(select(Assessment).where(Assessment.student_id.in_(student_ids))).all()
        if student_ids
        else []
    )
    assessment_student_ids = {row.student_id for row in assessments}

    children = []
    for student in students:
        children.append(
            {
                **_student_payload(student),
                "assessment_completed": student.id in assessment_student_ids,
                "dashboard_url": _dashboard_url(student.id),
                "summary_url": _summary_url(student.id),
            }
        )
    return {"parent": _parent_payload(parent), "children": children}


@router.post("/parents/{parent_id}/children", status_code=201)
def create_alpha_child(
    parent_id: str,
    request: AlphaChildCreate,
    session: Session = Depends(get_db_session),
):
    parent = _get_alpha_parent(session, parent_id)
    student = StudentProfile(
        parent_id=parent.id,
        name=request.nickname,
        grade_label=f"{request.grade}年级",
        persona=StudentPersona.real_child,
        is_real_child=True,
    )
    session.add(student)
    session.flush()
    session.add(AbilityProfile(student_id=student.id))
    session.commit()
    session.refresh(student)
    return {
        "student": _student_payload(student),
        "dashboard_url": _dashboard_url(student.id),
        "summary_url": _summary_url(student.id),
    }


@router.get("/parents/{parent_id}/children/{student_id}/summary")
def get_alpha_child_summary(
    parent_id: str,
    student_id: str,
    session: Session = Depends(get_db_session),
):
    _get_alpha_parent(session, parent_id)
    student = _get_parent_child(session, parent_id, student_id)
    assessment_count = len(
        session.exec(select(Assessment).where(Assessment.student_id == student_id)).all()
    )
    sentence_count = len(
        session.exec(select(SentenceTraining).where(SentenceTraining.student_id == student_id)).all()
    )
    essay_count = len(session.exec(select(Essay).where(Essay.student_id == student_id)).all())
    histories = session.exec(
        select(AbilityHistory).where(AbilityHistory.student_id == student_id)
    ).all()

    totals: dict[str, int] = defaultdict(int)
    for row in histories:
        totals[row.ability_name] += row.delta

    ability_changes = [
        {
            "ability_name": ability_name,
            "label": ABILITY_LABELS[ability_name],
            "delta": totals[ability_name],
        }
        for ability_name in ABILITY_ORDER
        if totals.get(ability_name)
    ]
    has_training = assessment_count + sentence_count + essay_count > 0

    return {
        "student": _student_payload(student),
        "assessment_completed": assessment_count > 0,
        "practice_counts": {
            "assessments": assessment_count,
            "sentence_trainings": sentence_count,
            "essays": essay_count,
        },
        "ability_changes": ability_changes,
        "recent_highlight": "孩子完成了第一次能力草图。" if assessment_count else None,
        "next_suggestion": (
            "继续练习把句子写具体。"
            if assessment_count
            else "先完成入门小试炼，生成第一张能力草图。"
        ),
        "empty_state": (
            None
            if has_training
            else "还没有训练记录。完成入门小试炼后，这里会出现第一份成长摘要。"
        ),
    }
```

```tsx
"use client";

import Link from "next/link";
import { useRouter } from "next/navigation";
import { use, useEffect, useState } from "react";
import { getAlphaChildSummary } from "../../../../../lib/api";
import { getStoredAlphaParentId } from "../../../../../lib/alphaParent";
import type { AlphaChildSummary } from "../../../../../lib/types";

export default function SummaryPage({
  params,
}: {
  params: Promise<{ studentId: string }>;
}) {
  const { studentId } = use(params);
  return <SummaryClient studentId={studentId} />;
}

function SummaryClient({ studentId }: { studentId: string }) {
  const router = useRouter();
  const [summary, setSummary] = useState<AlphaChildSummary | null>(null);
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    const parentId = getStoredAlphaParentId();
    if (!parentId) {
      router.replace("/alpha/start");
      return;
    }
    getAlphaChildSummary(parentId, studentId)
      .then(setSummary)
      .catch(() => setError("成长摘要加载失败，请稍后再试。"))
      .finally(() => setIsLoading(false));
  }, [router, studentId]);

  return (
    <main className="min-h-screen px-5 py-8 sm:px-8">
      <section className="mx-auto max-w-4xl space-y-6">
        {isLoading ? <p role="status">正在加载成长摘要...</p> : null}
        {error ? <p role="alert" className="font-semibold text-red-600">{error}</p> : null}
        {summary ? (
          <>
            <div className="rounded-lg border border-[var(--wen-border)] bg-white p-6 shadow-sm">
              <p className="text-sm font-semibold text-[var(--wen-muted)]">
                {summary.student.grade_label}
              </p>
              <h1 className="mt-2 text-3xl font-bold">{summary.student.name}的成长摘要</h1>
              {summary.empty_state ? (
                <p className="mt-4 rounded-lg bg-[var(--wen-bg)] p-4 font-semibold">
                  {summary.empty_state}
                </p>
              ) : null}
            </div>

            <section className="rounded-lg border border-[var(--wen-border)] bg-white p-6 shadow-sm">
              <h2 className="text-xl font-bold">最近练习</h2>
              <div className="mt-4 grid gap-3 sm:grid-cols-3">
                <p className="rounded-lg bg-[var(--wen-bg)] p-3 font-semibold">
                  入门小试炼 {summary.practice_counts.assessments} 次
                </p>
                <p className="rounded-lg bg-[var(--wen-bg)] p-3 font-semibold">
                  句子训练 {summary.practice_counts.sentence_trainings} 次
                </p>
                <p className="rounded-lg bg-[var(--wen-bg)] p-3 font-semibold">
                  小写作 {summary.practice_counts.essays} 次
                </p>
              </div>
            </section>

            <section className="rounded-lg border border-[var(--wen-border)] bg-white p-6 shadow-sm">
              <h2 className="text-xl font-bold">能力变化</h2>
              {summary.ability_changes.length > 0 ? (
                <div className="mt-4 grid gap-3 sm:grid-cols-2">
                  {summary.ability_changes.map((change) => (
                    <p
                      key={change.ability_name}
                      className="rounded-lg bg-[var(--wen-bg)] p-3 font-semibold"
                    >
                      {change.label} +{change.delta}
                    </p>
                  ))}
                </div>
              ) : (
                <p className="mt-3 text-[var(--wen-muted)]">
                  完成入门小试炼后，这里会显示能力变化。
                </p>
              )}
            </section>

            <section className="rounded-lg border border-[var(--wen-border)] bg-white p-6 shadow-sm">
              <h2 className="text-xl font-bold">最近亮点</h2>
              <p className="mt-3 text-[var(--wen-muted)]">
                {summary.recent_highlight ?? "还在等待第一条学习记录。"}
              </p>
              <h2 className="mt-6 text-xl font-bold">下一步建议</h2>
              <p className="mt-3 text-[var(--wen-muted)]">{summary.next_suggestion}</p>
              <Link
                href={`/children/${summary.student.id}`}
                className="mt-6 inline-flex rounded-lg bg-[var(--wen-orange)] px-5 py-3 font-semibold text-white"
              >
                进入孩子空间
              </Link>
            </section>
          </>
        ) : null}
      </section>
    </main>
  );
}
```

````markdown
# WenLingo Alpha Deployment Runbook

Date: 2026-05-25

## Purpose

Deploy V0.4.1a for 3-5 trusted Alpha families on Railway.

## Railway Project Layout

Use one Railway project with three services:

```text
wenlingo-postgres  Railway PostgreSQL service
wenlingo-api       FastAPI backend service, root directory apps/api
wenlingo-web       Next.js frontend service, root directory apps/web
```

The Alpha environment must use Railway PostgreSQL or another persistent PostgreSQL instance. Do not use local SQLite, a disposable demo database, or a database file tied to a developer machine.

## Architecture

```text
Browser
-> Railway wenlingo-web public domain
-> Railway wenlingo-api public domain
-> Railway wenlingo-postgres persistent PostgreSQL
-> server-side LLM provider
```

## Railway Services

### PostgreSQL

Create a Railway PostgreSQL service first. Use its `DATABASE_URL` for the backend service.

### Backend Service

Service:

```text
Name: wenlingo-api
Source: GitHub repo
Root Directory: apps/api
Start Command: uv run alembic upgrade head && uv run uvicorn app.main:app --host 0.0.0.0 --port $PORT
Public Networking: enabled
```

Backend variables:

| Variable | Railway value |
| --- | --- |
| `DATABASE_URL` | Reference the PostgreSQL service `DATABASE_URL` from Railway's variable reference picker. |
| `CORS_ALLOW_ORIGINS` | The generated public HTTPS domain for `wenlingo-web` after Public Networking is enabled. |
| `LLM_PROVIDER` | `http` |
| `LLM_API_KEY` | The server-side key from the selected LLM provider account. |
| `LLM_MODEL` | The model name selected for Alpha. |
| `LLM_BASE_URL` | The base URL from the selected LLM provider. |
| `LLM_PROMPT_VERSION` | `v0.2-quality-spine-2026-05-14` |

### Frontend Service

Service:

```text
Name: wenlingo-web
Source: GitHub repo
Root Directory: apps/web
Build Command: corepack pnpm install --frozen-lockfile && corepack pnpm build
Start Command: corepack pnpm start
Public Networking: enabled
```

Frontend variables:

| Variable | Railway value |
| --- | --- |
| `NEXT_PUBLIC_API_BASE_URL` | The generated public HTTPS domain for `wenlingo-api` after Public Networking is enabled. |

Set `NEXT_PUBLIC_API_BASE_URL` before building the frontend service because Next.js bakes `NEXT_PUBLIC_*` variables into the browser bundle at build time.

LLM keys must remain server-side on `wenlingo-api`. Do not expose LLM keys through `NEXT_PUBLIC_*` variables.

## Smoke Test

- Open the `wenlingo-api` public domain plus `/health` and confirm status is ok.
- Open the `wenlingo-web` public domain plus `/alpha/start`.
- Accept Alpha notice and create a child.
- Confirm child appears in `/parent/children`.
- Enter child dashboard and confirm `入门小试炼` is recommended.
- Complete assessment with the configured LLM provider.
- Return to dashboard and confirm main recommendation changes.
- Open parent summary and confirm real counts and ability changes appear.

## Manual Alpha Link Distribution

Send only the hosted `wenlingo-web` public domain plus `/alpha/start` to invited trusted families. Do not publish the link publicly.

## Backup and Deletion Note

Before inviting families, confirm Railway PostgreSQL backup/export access for the Alpha database. For deletion requests during V0.4.1a, identify the relevant `ParentUser.id` or `StudentProfile.id` and delete linked Alpha data manually after exporting a backup.

## Rollback

If Alpha entry breaks, remove or hide the `/alpha/start` link and redeploy the previous working Railway deployment. Keep the PostgreSQL service intact so created Alpha rows are not lost.
````
