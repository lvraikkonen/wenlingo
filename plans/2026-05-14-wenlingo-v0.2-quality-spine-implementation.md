# WenLingo V0.2 Quality Spine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the V0.2 quality spine: a child-testable essay revision loop for 小宇 with real-LLM-capable feedback, structured retry/fallback/logging, revision task persistence, and a warm baseline UI for the main path.

**Architecture:** Execute sequentially with a review gate after every task. The backend owns provider selection, schema validation, retry/fallback, persistence, and traceability; the frontend stays thin and renders the essay revision path with explicit task completion and child-friendly states. Do not dispatch implementation tasks in parallel because several tasks intentionally touch `ai_tasks.py`, `essays.py`, and frontend essay flow files.

**Tech Stack:** FastAPI, SQLModel/SQLAlchemy, Alembic, Pydantic, pytest, Next.js App Router, React 19, TypeScript, Tailwind CSS 4, Vitest, React Testing Library, Playwright.

```python
def get_llm_provider(settings: Settings = Depends(get_settings)) -> LLMProvider:
    provider = settings.llm_provider.strip().lower()
    if provider == "mock":
        return MockLLMProvider()
    if provider == "http":
        missing = [
            name
            for name, value in {
                "LLM_API_KEY": settings.llm_api_key,
                "LLM_MODEL": settings.llm_model,
                "LLM_BASE_URL": settings.llm_base_url,
            }.items()
            if not value.strip()
        ]
        if missing:
            raise HTTPException(
                status_code=503,
                detail=f"LLM http provider is missing configuration: {', '.join(missing)}",
            )
        return HttpJsonLLMProvider(
            api_key=settings.llm_api_key,
            model=settings.llm_model,
            base_url=settings.llm_base_url,
        )
    raise HTTPException(status_code=503, detail=f"Unsupported LLM_PROVIDER: {settings.llm_provider}")
```

Add runner:

```python
async def run_validated_llm_task(
    *,
    provider: LLMProvider,
    session: Session | None,
    task_type: TaskType,
    task_name: str,
    payload: dict,
    output_model: type[T],
    fallback: T,
    input_summary: str,
    prompt_version: str,
) -> LLMTaskResult[T]:
    errors: list[str] = []
    raw_response = ""
    provider_name = getattr(provider, "provider_name", provider.__class__.__name__)
    model_name = getattr(provider, "model_name", "unknown")

    for attempt_index in range(MAX_LLM_ATTEMPTS):
        try:
            response = await provider.complete_json(task_name, payload)
            raw_response = response.raw_response
            output = output_model.model_validate(response.parsed_json)
            log = None
            if session is not None:
                log = log_llm_result(
                    session=session,
                    task_type=task_type,
                    provider=response.provider,
                    model=response.model,
                    prompt_version=prompt_version,
                    input_summary=input_summary,
                    raw_response=response.raw_response,
                    output_json=output.model_dump(),
                    validation_ok=True,
                    error_message="",
                    retry_count=attempt_index,
                )
            return LLMTaskResult(output=output, log=log)
        except ValidationError as exc:
            errors.append(f"validation error: {exc}")
        except Exception as exc:
            errors.append(str(exc))

    log = None
    if session is not None:
        log = log_llm_result(
            session=session,
            task_type=task_type,
            provider=provider_name,
            model=model_name,
            prompt_version=prompt_version,
            input_summary=input_summary,
            raw_response=raw_response,
            output_json=fallback.model_dump(),
            validation_ok=False,
            error_message="; ".join(errors),
            retry_count=MAX_LLM_ATTEMPTS - 1,
        )
    return LLMTaskResult(output=fallback, log=log)
```
