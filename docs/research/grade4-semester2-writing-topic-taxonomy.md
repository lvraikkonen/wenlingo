# 四年级下册课内同步作文题型分类

Date: 2026-06-24
Source: 统编版四年级下册语文教材
Purpose: 为 Writing Castle 课前构思脚手架（审题/选材/素材卡/提纲）提供题型适配依据

---

## 总览

7 篇课内同步作文中：
- **叙事类（适配当前 V0.6a 模板）**: 1 篇（14%）
- **部分适配**: 1 篇（14%）
- **不适配（需要新模板）**: 5 篇（72%）

当前 V0.6a 固定模板 `起因/经过/结果/感受` + 固定素材卡 `事件/细节/心情收获`
只能覆盖课内作文的约 14-28%。

---

## 逐题分析

### 1. 我的乐园

| 维度 | 内容 |
|---|---|
| 作文类型 | 地点描写 + 生活体验 |
| 孩子需要想什么 | 哪个地方是"我的乐园"；这个地方长什么样；在这里做什么最开心；为什么这里是"乐园"而不是普通地方 |
| 内容来源 | 真实经历（去过的地方） |
| 推荐素材卡类型 | `地点样子` / `在这里做什么` / `最快乐的时刻` / `为什么是乐园` |
| 推荐提纲结构 | 这是什么地方 → 它长什么样 → 我在这里做什么 → 为什么它让我快乐 |
| 当前 V0.6a `起因/经过/结果/感受` 是否适配 | ❌ 不太适配。地点描写不需要"起因""结果"，需要的是空间描写+活动叙述+情感表达。 |
| 是否需要新模板 | 是 — `place_my_paradise` |

### 2. 我的奇思妙想

| 维度 | 内容 |
|---|---|
| 作文类型 | 想象发明 + 说明介绍 |
| 孩子需要想什么 | 我想发明什么东西；它长什么样；它有什么神奇的功能；它怎么用；它能帮人们解决什么问题 |
| 内容来源 | 孩子自己想象出来的设定（不是真实经历） |
| 推荐素材卡类型 | `样子` / `功能` / `用处` / `为什么想发明它` |
| 推荐提纲结构 | 我想发明什么 → 它长什么样 → 它有什么神奇功能 → 它能帮人们做什么 → 我的期待 |
| 当前 V0.6a `起因/经过/结果/感受` 是否适配 | ❌ 不适配。想象发明不需要"起因/经过/结果"叙事弧，需要的是说明+想象展开。 |
| 是否需要新模板 | 是 — `invention_idea` |

### 3. 游____

| 维度 | 内容 |
|---|---|
| 作文类型 | 游记 / 写景 / 顺序描写 |
| 孩子需要想什么 | 去了什么地方；按什么顺序游览；每个地方看到了什么（重点景物）；游览中有什么感受 |
| 内容来源 | 真实经历（去过的地方） |
| 推荐素材卡类型 | `游览路线` / `重点景物` / `细节描写` / `游览感受` |
| 推荐提纲结构 | 去了哪里 → 先看到什么 → 再走到哪里（重点景物详写） → 最后看到什么 → 游览感受 |
| 当前 V0.6a `起因/经过/结果/感受` 是否适配 | ⚠️ 部分适配。如果理解为"起因=出发、经过=游览过程、结果=游览结束、感受=心情"，勉强可用。但缺少"游览顺序"和"重点景物选择"的引导，而这是游记类作文的核心写作技巧。 |
| 是否需要新模板 | 是 — `travel_writing`（优先级低于完全不适配的类型） |

### 4. 我的"自画像"

| 维度 | 内容 |
|---|---|
| 作文类型 | 写人 / 自我介绍 |
| 孩子需要想什么 | 我长什么样；我是什么性格；我喜欢做什么（爱好特长）；用一个具体事例说明我的特点 |
| 内容来源 | 真实经历（自己的特点+事例） |
| 推荐素材卡类型 | `外貌` / `性格` / `爱好特长` / `最能体现特点的事例` |
| 推荐提纲结构 | 我是谁（整体印象） → 外貌特点 → 性格特点（用一件事说明） → 爱好或特长 → 这就是我 |
| 当前 V0.6a `起因/经过/结果/感受` 是否适配 | ❌ 不适配。写人不需要叙事弧，需要的是特点归纳+事例支撑。 |
| 是否需要新模板 | 是 — `self_portrait` |

### 5. 故事新编

| 维度 | 内容 |
|---|---|
| 作文类型 | 想象故事 / 改编叙事 |
| 孩子需要想什么 | 选哪个老故事；保留什么（人物、基本设定）；改变什么（结局、关键情节）；新故事想传达什么 |
| 内容来源 | 已有故事框架 + 孩子自己想象的新情节/新结局 |
| 推荐素材卡类型 | `原故事基础` / `保留的人物和设定` / `要改变的情节` / `新结局` / `新想传达的意思` |
| 推荐提纲结构 | 原故事是什么 → 保留什么 → 从哪里开始改变 → 新情节 → 新结局 → 新故事的意思 |
| 当前 V0.6a `起因/经过/结果/感受` 是否适配 | ⚠️ 部分适配。叙事结构可以用"起因=原故事背景、经过=新情节展开、结果=新结局、感受=新寓意"，但缺少"原故事基础"和"从哪里开始改变"这两个《故事新编》独有的关键构思步骤。 |
| 是否需要新模板 | 是 — `story_rewrite` |

### 6. 我的动物朋友

| 维度 | 内容 |
|---|---|
| 作文类型 | 动物描写 / 情境介绍 |
| 孩子需要想什么 | 在什么情境下介绍这个动物（如请邻居帮忙照顾/找丢失的动物/跟朋友介绍）；动物长什么样；有什么习性特点；和"我"之间有什么感情/故事 |
| 内容来源 | 真实经历（养过的动物）**或** 创设的情境（没养过也可以想象一个情境） |
| 推荐素材卡类型 | `介绍情境` / `外形特点` / `习性特点` / `我和它的故事或感情` |
| 推荐提纲结构 | 在什么情境下介绍它 → 它长什么样 → 它有什么特别的地方（习性） → 我和它之间的一件事 → 我对它的感情 |
| 当前 V0.6a `起因/经过/结果/感受` 是否适配 | ❌ 不太适配。虽然包含叙事元素（"一件事"），但核心是描写+情境说明，不是叙事弧。教材明确允许"如果没有养过，也可以创设一个情境"——这突破了"真实经历"的边界。 |
| 是否需要新模板 | 是 — `animal_friend` |

### 7. 我学会了____

| 维度 | 内容 |
|---|---|
| 作文类型 | 成长经历 / 事件叙事 |
| 孩子需要想什么 | 学会了什么技能；学的过程遇到了什么困难；怎么克服的；学会后的感受 |
| 内容来源 | 真实经历 |
| 推荐素材卡类型 | `学什么` / `遇到的困难` / `关键动作或画面` / `学会后的心情` |
| 推荐提纲结构 | 起因（为什么要学） → 经过（怎么学的、遇到什么困难、怎么克服） → 结果（学会了） → 感受（心情、收获） |
| 当前 V0.6a `起因/经过/结果/感受` 是否适配 | ✅ 很适配。这是标准的成长叙事，《我学会了____》是最适合当前 V0.6a 模板的题目。 |

## 内容来源分类

按"内容从哪里来"对 7 篇题目进行分类：

| 内容来源类型 | 题目 | 数量 |
|---|---|---|
| 真实经历 | 我的乐园、游____、我的"自画像"、我学会了____ | 4 |
| 想象创造 | 我的奇思妙想、故事新编 | 2 |
| 混合（真实+可创设情境） | 我的动物朋友 | 1 |

**关键发现**：7 篇中有 3 篇的内容来源不完全是"真实经历"。这意味着 V0.6a 的"AI 不编造孩子 lived content"原则在表述上过于狭窄——对于想象类和情境创设类作文，孩子需要的是"自己做选择"而不是"回忆真实事件"。

## 素材卡类型汇总

按题目聚合后，需要的素材卡类型远不止当前 V0.6a 的 3 种：

| 素材卡类别 | 适用题目 | 频次 |
|---|---|---|
| 事件/做了什么 | 我的乐园、游____、我的"自画像"、我学会了____、我的动物朋友 | 5 |
| 细节/样子/外貌 | 我的乐园、我的奇思妙想、游____、我的"自画像"、我的动物朋友 | 5 |
| 感受/心情/收获 | 全部 7 篇 | 7 |
| 功能/特点/习性 | 我的奇思妙想、我的动物朋友 | 2 |
| 人物/性格 | 我的"自画像" | 1 |
| 情境/背景 | 我的动物朋友、故事新编 | 2 |
| 故事元素（保留/改变） | 故事新编 | 1 |
| 顺序/路线 | 游____ | 1 |

**关键发现**：`感受/心情/收获` 是唯一跨所有题目的素材卡类型。`事件` 和 `细节` 覆盖 5/7 篇。但特定题目需要特定类型的卡（功能、性格、情境等），这些不能通过固定 3 槽覆盖。

## 提纲结构汇总

| 题目 | 推荐提纲结构 | 与 `起因/经过/结果/感受` 的关系 |
|---|---|---|
| 我的乐园 | 是什么 → 长什么样 → 做什么 → 为什么快乐 | 不同 |
| 我的奇思妙想 | 发明什么 → 长什么样 → 功能 → 用处 → 期待 | 完全不同 |
| 游____ | 去哪 → 先看到 → 重点景物 → 最后 → 感受 | 勉强可映射 |
| 我的"自画像" | 是谁 → 外貌 → 性格+事例 → 爱好 → 这就是我 | 完全不同 |
| 故事新编 | 原故事 → 保留 → 改变起点 → 新情节 → 新结局 → 新寓意 | 可映射但缺关键步骤 |
| 我的动物朋友 | 情境 → 外形 → 习性 → 一件事 → 感情 | 不同 |
| 我学会了____ | 起因 → 经过 → 结果 → 感受 | 完全相同 |

---

## 对 V0.6a 的结论

1. 当前 `起因/经过/结果/感受` 模板只适配 1/7 课内作文。这不是 minor limitation，是 **核心产品缺口**。
2. 但由于 V0.6a 的 skip 设计允许孩子跳过提纲直接写初稿，这个缺口在当前版本不阻塞使用——孩子仍能走完"审题→选材→写初稿→点评→修改→结算"闭环，只是提纲模板不对。
3. **建议 V0.6b 优先做"课内同步作文题型适配 v1"，将 AI 出题作文延后到 V0.6c。** 原因是：课内同步作文有明确的教材依据，题型适配的优先级应该高于增加新入口。
4. `topic_type` + `scaffold_template` 概念应该在 V0.6b spec 中引入。这不是过度工程——四年级下册 7 篇中 5 篇需要新模板，说明模板化是刚需而非 nice-to-have。

## V0.6b 建议的 topic_type 枚举（第一版）

```python
class TopicType(str, Enum):
    LEARNED_SKILL = "learned_skill"        # 我学会了____ — 当前 V0.6a 模板
    MY_PARADISE = "my_paradise"            # 我的乐园
    INVENTION_IDEA = "invention_idea"       # 我的奇思妙想
    TRAVEL_WRITING = "travel_writing"       # 游____
    SELF_PORTRAIT = "self_portrait"        # 我的"自画像"
    STORY_REWRITE = "story_rewrite"         # 故事新编
    ANIMAL_FRIEND = "animal_friend"        # 我的动物朋友
    GENERIC_NARRATIVE = "generic_narrative" # 兜底 — 当前 V0.6a 模板
```

每个 `topic_type` 绑定：
- 推荐素材卡类型（2-5 种）
- 推荐提纲结构（3-5 段）
- 选材问题的引导方向
- 审题三卡的题目特定提示
